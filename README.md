# 🎙️ كرت الصوت الوهمي — Abu fahad © | Audio Studio

برنامج معالجة صوت فورية (Real-Time Low-Latency DSP) مخصص للمايك بمؤثرات **تضخيم الصوت والبيس العميق** مع **صدى قوي جداً ومتكرر**، بواجهة كلاسيكية مستوحاة من كروت Creative Sound Blaster EAX مع دعم الربط المباشر بـ Voicemeeter والديسكورد والألعاب.

---

## ✨ المميزات الرئيسية
- **تضخيم عميق وضخم (Preamp + Bass Boost + Body + Sub-Harmonic + Drive):**
  - رفع قوة المايك الأساسية حتى `+24 dB`.
  - تضخيم البيس والترددات التحتية لإعطاء فخامة وضخامة صوتية بدون تشويش.
  - تشبع أنبوبي (Tube Saturation & Soft-Clipping) لرفع مستوى الصوت وإبراز الكلمات.
- **صدى قوي جداً (Multi-Tap Stereo Echo & Hall Reverb):**
  - تحكم بقوة الصدى حتى `200%` ليكون الصدى مساوياً أو أعلى من الصوت الأصلي.
  - تكرار عالي (Feedback حتى `90%`) مع فلترة أمان لمنع الصفير.
  - انتشار ستيريو واسع وتردد قاعة احترافي.
- **10 وزنيات جاهزة:**
  - `وزنية أبو فهد (الأساسية)`
  - `تضخيم وحشي + صدى عالي`
  - `صدى متكرر قوي`
  - `صدى عميق وطويل`
  - `تضخيم ثقيل + صدى سريع`
  - `صدى واسع ومفتوح`
  - `صوت جهوري وواضح`
  - `صدى ناعم ومرتب`
  - `صوت مكتوم وثقيل`
  - `تضخيم صافي + صدى خفيف`
- **تحكم فوري (EAX Amount Slider):**
  - شريط تمرير سريع للتحكم بنسبة المؤثرات من 0% إلى 100%.
- **توجيه سهل وتكامل مع Voicemeeter:**
  - زر تلقائي لفتح Voicemeeter Banana وتوجيه المايك إلى مسار `B1` مباشرة.
  - إمكانية تشغيل المراقبة وسماع صوتك بالسماعة (AUX / Monitor).
- **أداء عالي واستهلاك معالج ضئيل:**
  - محرك NumPy / SciPy مكتوب بالكامل لمعالجة كتل 512 عينة بزمن استجابة أقل من 10ms واستهلاك ~3% فقط من نواة معالج واحدة.

## 🚀 طريقة التشغيل

### من الكود المصدري (Python):
```bash
pip install -r requirements.txt
python app.py
```

### أو من النسخة الجاهزة (EXE):
شغّل ملف `تشغيل كرت لابوبو.bat` أو افتح `AbuFahad_AudioStudio.exe` مباشرة من المجلد.

---

## 🎮 الإعداد في الديسكورد والألعاب
1. داخل البرنامج، اختر المايك حقك في خانة **المايك**.
2. اختر `Voicemeeter Input` في خانة **المخرج**.
3. اضغط **شغّل واضبط فويس ميتر (B1 + AUX)**.
4. في إعدادات ديسكورد أو اللعبة، اختر المايك: `Voicemeeter Out B1`.

## 📁 هيكلة المشروع
- `app.py` — الواجهة الرسومية الكاملة وعناصر التحكم وشريط EAX الكلاسيكي.
- `dsp_engine.py` — محرك معالجة الإشارات الرقمية والفلاتر ومصفوفات الصدى.
- `audio_engine.py` — إدارة مسارات الصوت والإدخال/الإخراج عبر Windows WASAPI.
- `voicemeeter_bridge.py` — جسر الربط التلقائي بمكتبة VoicemeeterRemote API.
- `ui_widgets.py` — عناصر الواجهة المخصصة ورسم التدرجات وشريط التمرير.
- `settings.json` — حفظ واسترجاع الإعدادات والأجهزة والوزنية المختارة تلقائياً.
